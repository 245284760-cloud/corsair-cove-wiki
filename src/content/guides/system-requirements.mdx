## Supported operating system

The official [Steam listing](https://store.steampowered.com/app/1368140/Corsair_Cove/) lists Windows 10 64-bit as the minimum operating system. A 64-bit Windows installation is required; 32-bit Windows does not meet the published requirement.

## Minimum requirements

These are the official minimum specifications for running Corsair Cove:

| Component | Minimum |
| --- | --- |
| Operating system | Windows 10 64-bit |
| Processor | Intel Core i7-7700 or AMD Ryzen 5 1600 |
| Memory | 8 GB RAM |
| Graphics | NVIDIA GeForce GTX 1660 Super 6 GB or AMD Radeon RX 5600 XT 6 GB |
| DirectX | Version 12 |
| Storage | 30 GB available space |
| Storage type | SSD recommended |

Meeting the minimum specification is a baseline for starting the game, not a promise of a particular frame rate or graphics preset.

## Recommended requirements

For the official recommended target, Steam lists:

| Component | Recommended |
| --- | --- |
| Operating system | Windows 10 64-bit |
| Processor | Intel Core i5-9600K or AMD Ryzen 5 3600 |
| Memory | 16 GB RAM |
| Graphics | NVIDIA GeForce RTX 2070 8 GB or AMD Radeon RX 6600 XT 8 GB |
| DirectX | Version 12 |
| Storage | 30 GB available space |

## Storage and hardware notes

Reserve at least 30 GB of available space for the game. Steam marks an SSD as recommended in both requirement tiers. An SSD recommendation does not replace the CPU, memory, or GPU requirements. Laptop GPU names and power limits vary, so compare the actual GPU model and available VRAM rather than assuming a mobile part matches its desktop name.

## Check your PC before buying

On Windows, open **Settings → System → About** to check the processor, installed RAM, and system type. Open **Settings → System → Display → Advanced display** or run `dxdiag` to identify the graphics adapter and DirectX version. In Steam, open the game's Properties and check the Installed Files page for the storage location and free space before installing.

Compare each component against the table, not just one headline specification. If your system is below the minimum CPU or GPU, treat that as a compatibility risk even when it has enough RAM or disk space.

## Fix startup or performance problems

If the game will not start, first confirm that Windows is 64-bit, install pending Windows and GPU-driver updates, and verify the game files in Steam. For stutter or long loads, close background applications, make sure the SSD has free space, and lower graphics settings. If the issue continues, use the [troubleshooting guide](/troubleshooting/) to collect a reproducible report; do not claim that unsupported hardware is a confirmed game bug.
