## 四、明确不做

| 页面方向 | 原因 |
|---|---|
| OSRS、second pirate camp、resource area | 同名地点污染 |
| review、metacritic | 媒体和视频意图占优 |
| trainer、cheat engine、crack、torrent | 作弊或盗版意图 |
| codes | 没有官方兑换码，数据中也没有进入高流量区 |
| achievements | 未进入前 100，素材不足 |
| production chains、best ships、best captains、principle points | 初稿推断词，没有进入当前可见高流量前 100；等 Search Console 或更多数据再决定 |

## 五、内链规则

- 首页只链接 Guide Hub、平台、发售、价格和最新 3–5 篇核心攻略。
- Guide Hub 聚合全部攻略，按“新手—人口—船只—建造—资源—故障”分组。
- 资源页互相交叉链接；建船页链接人口、绳索和打捞码头页。
- 发售页链接价格、平台和配置页；平台页链接多人模式页。
- 每个页面只设一个主关键词，同义词和近义问题在正文 FAQ 中承接，避免关键词蚕食。
